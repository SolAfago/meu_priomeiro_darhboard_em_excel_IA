# 📊 Meu Primeiro Dashboard em Excel com IA

> Meu primeiro projeto de dashboard em Excel utilizando Inteligência Artificial, com foco em análise de dados, visualização interativa e organização de informações de forma prática e intuitiva.

## 📌 Sobre o projeto

Este projeto foi desenvolvido para praticar a criação de dashboards no Microsoft Excel utilizando recursos de Inteligência Artificial como apoio durante o desenvolvimento.

O objetivo é transformar uma base de dados em um painel visual que facilite a interpretação das informações por meio de indicadores, gráficos e organização eficiente dos dados. A combinação entre Excel e IA permite acelerar a construção de dashboards e tornar a análise mais acessível. <a href="https://www.guiadoexcel.com.br/criar-dashboard-online-com-excel-e-claude-ou-chatgpt/" target="_blank">Guia do Excel</a>.

## ✨ Funcionalidades

- 📈 Dashboard visual e intuitivo
- 📊 Indicadores (KPIs)
- 📉 Gráficos para análise dos dados
- 🎯 Organização das informações em um único painel
- 🤖 Apoio da IA na construção e estrutura do projeto

## 🛠️ Tecnologias utilizadas

- Inteligência Artificial (ChatGPT)
